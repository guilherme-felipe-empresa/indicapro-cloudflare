# IndicaPro

Versão independente para seu Supabase e deploy na Cloudflare Workers via Git.

Comece por **[GUIA_CLOUDFLARE.md](GUIA_CLOUDFLARE.md)**: banco, variáveis, importação
na Cloudflare e criação do primeiro administrador.

- Build: `npm run build`
- Deploy: `npm run deploy`
- Instalação reproduzível: `npm ci`
- Desenvolvimento: `npm run dev`

As telas e regras do sistema original foram preservadas. Configure seu Supabase
para usar autenticação, dados e arquivos. Não há credenciais incluídas no código.
